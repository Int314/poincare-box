# ポアンカレの箱

密閉された箱に100個の粒子が入っています。全部が左半分に集まる瞬間を待っています。
理論上、それは必ず起きます。期待待ち時間は約 1.2×10²⁴ 年（宇宙年齢の約8.7兆倍）です。

熱力学第二法則は統計的な法則にすぎないので、エントロピーの自発的減少は禁止されていません。
ただ待てる人がいないだけです。

## 検証できます

粒子の配置は保存されていません。`SHA-256(poincare-box-v1:<tick>)` の先頭100ビットから
毎回導出しているので、誰でも全履歴を再現できます。

```bash
npm install
npm run verify
```

導出ロジックの全体は [public/core.js](public/core.js) にあります。サイトからも同じファイルが
そのまま配信されているので、ブラウザで開けば表示されている数字の出どころを確認できます。

## 開発

```bash
npm run dev
```

仕様は [docs/spec.md](docs/spec.md)。`public/core.js` の凍結パラメータは変更禁止です（§2 凍結条項）。
